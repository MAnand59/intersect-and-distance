# Security policy

## Supported versions

Security fixes are provided for the latest published minor version.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/MAnand59/intersect-and-distance/security/advisories/new). Include affected versions, impact, reproduction details, and any suggested mitigation.

Do not disclose an unresolved vulnerability in a public issue. You should receive an initial response within seven days. Valid reports will be coordinated privately through remediation and disclosure.
